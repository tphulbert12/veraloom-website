# Veraloom Brand Guidelines

**Version:** 1.0  
**Last Updated:** July 2026

---

# Brand Mission

Veraloom exists to help families preserve, organize, and relive the moments that matter most—photos, videos, stories, voice recordings, and keepsakes woven together for generations.

---

# Brand Personality

Every Veraloom experience should feel:

- Warm
- Timeless
- Trustworthy
- Intentional
- Hopeful
- Family-centered

The brand should never feel:

- Corporate
- Cold
- Cluttered
- Overly technical
- Trendy for the sake of being trendy

# Official Color Palette

| Purpose | Color | Hex |
|---------|-------|------|
| Primary | Deep Navy | #031B3F |
| Secondary | Teal | #32858B |
| Accent | Bright Orange | #F45528 |
| Accent | Golden Orange | #F0A22F |
| Background | Soft Warm Ivory | #FCFAF5 |
| Supporting | Slate Blue | #5B6B7D |
| Neutral | White | #FFFFFF |

## Color Usage Rules

- **Deep Navy (#031B3F)** is the primary brand color and should be used for navigation, headings, primary buttons, and key UI elements.
- **Teal (#32858B)** is used for links, secondary actions, icons, and interactive highlights.
- **Bright Orange (#F45528)** is reserved for emphasis and small accent moments. Do not use it as the default button color.
- **Golden Orange (#F0A22F)** is used sparingly for decorative accents and illustrations.
- **Soft Warm Ivory (#FCFAF5)** is the default page background.
- **White (#FFFFFF)** is used for cards, forms, and modal surfaces to create subtle separation from the page background.
- **Slate Blue (#5B6B7D)** is used for secondary text, borders, and supporting interface elements.

# Typography

## Primary Typeface

**Manrope**

Use the following weights:

| Weight | Usage |
|---------|-------|
| 400 | Body text |
| 500 | Navigation |
| 600 | Headings and buttons |

Avoid using heavier weights (700+) unless there is a very specific reason.

## Typography Principles

- Keep typography clean and modern.
- Never use ALL CAPS for primary calls to action.
- Favor generous whitespace over oversized text.
- Headings should feel confident, not aggressive.
- Body text should prioritize readability.

Typical sizing:

- Hero headings: 52–60px
- Section headings: 36–42px
- Body text: 18px
- Small text: 14–16px

# Illustration & Photography Style

## Illustration Style

Illustrations should feel:

- Warm
- Timeless
- Storybook-inspired
- Handcrafted
- Calm
- Family-centered

Preferred subjects include:

- Family keepsakes
- Memory books
- Journals
- Printed photographs
- Audio waveforms
- Cameras
- Clouds
- Nature
- Leaves
- Gentle woven textures

Avoid:

- Generic SaaS illustrations
- Harsh geometric artwork
- Neon colors
- Heavy 3D graphics
- Corporate vector art
- Abstract "blob" graphics

---

## Photography Style

Photography should always emphasize:

- Real families
- Genuine emotion
- Natural light
- Golden hour when appropriate
- Authentic candid moments
- Multi-generational relationships
- Everyday memories

Avoid:

- Staged business photos
- Office environments
- Generic stock photography
- Artificial poses
- Overly filtered images
- Cold or clinical lighting

# User Interface Principles

The Veraloom interface should feel calm, welcoming, and timeless.

Every screen should prioritize emotional clarity over visual complexity.

## Overall Feel

The interface should feel:

- Warm
- Elegant
- Calm
- Premium
- Trustworthy
- Simple

Users should immediately feel comfortable trusting Veraloom with their family's memories.

---

## Layout

Use generous whitespace.

Avoid crowded interfaces.

Content should breathe.

Sections should feel organized and effortless.

---

## Buttons

### Primary Button

- Deep Navy (#031B3F)
- White text
- Manrope SemiBold
- 16px corner radius

### Secondary Button

- White background
- Deep Navy border
- Deep Navy text

### Text Button

- Teal (#32858B)
- No border
- Simple hover effect

Bright Orange should never become the primary button color.

---

## Cards

Cards should:

- Use White (#FFFFFF)
- Sit on the Soft Warm Ivory background (#FCFAF5)
- Have soft rounded corners
- Use subtle shadows
- Never feel heavy or overly elevated

---

## Visual Style

Avoid:

- Glassmorphism
- Neon effects
- Loud gradients
- Busy backgrounds
- Excessive animations

Prefer:

- Soft transitions
- Gentle shadows
- Clean spacing
- Warm illustration
- Meaningful photography
